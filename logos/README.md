# Company logos

Put a company's logo here as a PNG named after its id, and the site uses it automatically on the next update.

- IPOs: `mksons.png`, `bombaycoated.png`, `jio.png`, `bls.png`, `maxwell.png` … (the id in `index.html`)
- Stocks: the NSE symbol, e.g. `RELIANCE.png`, `TCS.png`, `BAJAJ-AUTO.png` (`MM.png` for M&M)

Without a file here, the site shows the company's own website icon where it knows the site, otherwise a letter badge.
